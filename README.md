# Лабораторна робота № 6 — Автоматизація тестування вебінтерфейсу (Playwright)

**Дисципліна:** Автоматизація тестування  
**Варіант:** 5  
**Об’єкт тестування:** [Swag Labs (SauceDemo)](https://www.saucedemo.com)

## Опис проєкту

Проєкт містить автоматизовані E2E-тести вебінтерфейсу демонстраційного магазину Swag Labs, реалізовані за допомогою **Playwright** та **TypeScript** у браузерах **Chromium** та **Firefox**.

### Структура проєкту

- `playwright.config.ts` — конфігурація Playwright (базова URL-адреса, таймаути, трасування та знімки екрана при падінні, проєкти `chromium` і `firefox`).
- `tests/data.ts` — тестові облікові записи (`standard_user`, `locked_out_user`, `performance_glitch_user`).
- `tests/login.spec.ts` — позитивні та негативні сценарії автентифікації.
- `tests/inventory.spec.ts` — тести каталогу товарів (кількість елементів, сортування за зростанням ціни, додавання та видалення товарів із кошика з використанням `.filter()`).
- `tests/sidebar.spec.ts` — індивідуальне завдання (Варіант 5): відкриття бічного меню, перевірка складу його пунктів та вихід із системи через «Logout» із поверненням на сторінку входу.

## Основні команди

```bash
# Встановлення залежностей та браузерів
npm install
npx playwright install --with-deps chromium firefox

# Запуск усіх тестів у Chromium та Firefox
npm test

# Відкриття HTML-звіту
npm run test:report

# Запуск тестів в інтерактивному UI-режимі
npm run test:ui
```
