# Опис

Цей проєкт створено в рамках першої лабораторної роботи з дисципліни "Автоматизація тестування". Метою роботи є налаштування базового середовища для розробки та тестування з використанням TypeScript, ESLint, Prettier та тестового фреймворку Vitest.

# Структура проєкту

Типова структура цього проєкту виглядає наступним чином:

node_modules/ — встановлені залежності проєкту (генерується автоматично).

src/ — тека для основного вихідного коду (якщо є).

tests/ — тека, що містить файли з тестами (Vitest).

.gitignore — перелік файлів та тек, які ігноруються системою контролю версій Git.

package.json — конфігураційний файл проєкту, що містить список залежностей та скрипти (наприклад, npm test).

tsconfig.json — файл конфігурації для компілятора TypeScript.

README.md — цей файл з описом проєкту.

## Інструкція зі встановлення

Для того, щоб розгорнути проєкт локально, вам знадобиться встановлений Node.js.

Склонуйте репозиторій на свій комп'ютер.

Відкрийте термінал у теці проєкту (qa-automation).

Виконайте команду для встановлення всіх необхідних залежностей:

npm install


### Інструкція із запуску

Для запуску автоматизованих тестів за допомогою Vitest використовуйте наступну команду у терміналі:

npm test


Для запуску інструментів перевірки якості коду (лінтер та форматування), якщо вони налаштовані у package.json, можна використовувати:

npm run lint
npm run format
